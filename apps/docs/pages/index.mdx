  <div className="mx-grid">
    <a className="mx-card" href="/docs/concepts#mandate"><span className="mx-icon">✍︎</span><b>Signed, scoped authority</b><span>Grant an agent exactly what it needs: an action, a resource, a limit, a list of recipients, a lifetime. Signed by the issuer, so it can't be forged.</span></a>
    <a className="mx-card" href="/docs/concepts#delegation"><span className="mx-icon">↧</span><b>Delegation that only narrows</b><span>Agents can hand other agents a smaller slice, never a bigger one. Escalation is rejected before anything is stored.</span></a>

    <a className="mx-card" href="/docs/deny-codes"><span className="mx-icon">?</span><b>Every decision explained</b><span>ALLOW with the full chain of evidence, or DENY with a stable reason code like AMOUNT_EXCEEDED or ANCESTOR_REVOKED.</span></a>
    <a className="mx-card" href="/arkiv/schema"><span className="mx-icon">◆</span><b>Public, tamper-proof record</b><span>Mandates live on Arkiv, published from the issuer's own wallet. Revocations can't be deleted, not even by their issuer.</span></a>
