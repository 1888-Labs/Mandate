```bash [Ask before acting]
# InvoiceAgent may spend $300. It asks for $700.
curl https://mandate-94oq.onrender.com/v1/authorize \
  -H 'content-type: application/json' -d '{
    "subject": "0x97e80edf5d361855f64ff09a3d2cbf37b9f7e772",
    "action": "transfer",
    "resource": {"kind": "wallet", "id": "treasury-demo"},
    "amount": 700,
    "recipient": "AWS"
  }'
```

```json [Get an explained answer]
{
  "decision": "DENY",
  "reason": "AMOUNT_EXCEEDED",
  "message": "Requested 700 exceeds the delegated maximum of 300.",
  "requestedAmount": 700,
  "maximumAmount": 300,
  "delegationPath": ["0xa090…d2a4", "0x2141…44c4", "0x97e8…7772"]
}
```

```bash [CLI]
mandate check --agent invoice-agent --action transfer \
  --resource wallet:treasury-demo --amount 700 --recipient AWS

# ✗ DENIED  AMOUNT_EXCEEDED  (requested $700, maximum $300)
```

    <ol className="mx-steps">
      <li><b>Grant.</b> Alice lets FinanceAgent transfer up to $1,000, to AWS only, and pass some of that on.</li>
      <li><b>Delegate.</b> FinanceAgent gives InvoiceAgent a smaller slice: up to $300.</li>
      <li><b>Check.</b> Before paying, the tool asks Mandate. $200 to AWS is ALLOW. $700 is DENY.</li>
      <li><b>Revoke.</b> Alice revokes her grant. Both agents lose their authority on the next check.</li>
    </ol>

```rust [Delegation only narrows]
// M2 gives InvoiceAgent $300 of FinanceAgent's $1000.
can_delegate(&m1, &m2)?; // Ok: M2 only narrows M1.

// Now FinanceAgent tries to hand out $5000.
let escalated = sign_mandate(
    &UnsignedMandate {
        constraints: Constraints {
            max_amount: Some(5000),
            ..m2.constraints.clone()
        },
        ..m2.unsigned()
    },
    &finance_agent,
)?;
assert_eq!(
    can_delegate(&m1, &escalated),
    Err(DelegationError::AmountEscalation),
);
```
