:::code-group

```bash [Give the agent a task]
# On the agent Sprite. It holds only its signing key.
mandate-agent 'Add a line to README.md directly on main.'

✓ allow  GET repos/dicethedev/mandate-demo/contents/README.md  (HTTP 200)
✗ DENY   PUT repos/dicethedev/mandate-demo/contents/README.md  (HTTP 403)
         Target main is not one of the allowed: agent/work.
```

```json [The Warden explains]
{
  "decision": "deny",
  "reason": "RECIPIENT_NOT_ALLOWED",
  "message": "Target main is not one of the allowed: agent/work.",
  "action": "contents.write",
  "resource": "github:dicethedev/mandate-demo",
  "recipient": "main",
  "delegationPath": ["0x4f1b…5ae4", "0x818c…2a90"]
}
```

```bash [Pin its model]
# The owner lets the agent think with one model only.
curl -X POST "$WARDEN/v1/admin/mandates" \
  -H "authorization: Bearer $WARDEN_ADMIN_TOKEN" \
  -H 'content-type: application/json' -d '{
    "subject": "0xAGENT",
    "action": "model.chat",
    "resource": "ollama:cloud",
    "allowedRecipients": ["gpt-oss:120b"]
  }'
```

```bash [Self-host]
# The same Warden anywhere, with Docker.
docker compose up -d warden     # dashboard on http://localhost:8080
docker compose run --rm agent mandate-agent "List the open issues"
```
